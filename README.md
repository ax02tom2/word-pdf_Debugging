# 文件（PDF / Word）智能檢核與列印分析工具 - 系統規格說明書

本規格書旨在提供完整的專案藍圖與技術邏輯，供後續開發與 AI 協作使用。本工具定位為一個基於 **Streamlit** 與 **Python** 打造的網頁應用程式，強調零本機複雜環境依賴、高隱私性（本地唯讀解析），並針對工程報告與大型專案文件進行智慧檢核。

---

## 1. 核心功能需求

### 1.1 智慧彩色頁辨識與分流列印（核心難點）
系統需自動掃描 PDF 文件每一頁，根據內容與排版判定該頁是否必須「彩印」，並自動區分 **A3 尺寸** 與 **A4 尺寸**，最終輸出標準的區段頁碼格式（例如：`2-3、5、8-10`，以頓號「、」分隔，連續頁合併）。

*   **強制黑白判定（絕對維持黑白）**：
    *   文件內含「**雨量**」或「**降雨**」相關圖表、統計表、數據的頁面，**絕對強制判定為黑白頁**，不受任何自動像素與網底干擾影響。
    *   一般純文字頁、單純數據表格（即使帶有淺綠色、灰色或淡色背景網底），必須透過演習過濾，**不可誤判為彩色頁**。
*   **強制彩印判定（特定工程成果圖表）**：
    *   頁面內容包含以下關鍵字或圖表特徵時，**強制納入彩印清單**：
        1. 「**工作進度表**」或「**進度表**」（甘特圖等彩色進度條）。
        2. 「**GPS**」或「**GNSS**」相關變位歷時曲線圖。
        3. 「**雙軸傾斜計**」相關傾斜量歷時曲線圖。
        4. 「**立體投影圓分析**」、「**立體投影圓**」或與「**位態**」分析相關的彩色投影成果圖。
    *   其他大面積彩色照片、衛星空拍圖、地形變異比對圖（色彩飽和度與色差超過安全門檻者）。

### 1.2 圖表號連續性與跳號檢核
*   自動擷取內文中的圖表標籤（如 `圖 1-1`、`表 2-1`、`Figure 1` 等）。
*   **過濾機制**：不對內文「重複提及」同一圖表號進行報錯（避免將正常引用誤判為重複）。
*   **異常偵測**：專注檢查是否有**跳號**（例如編號 1 直接跳 3）或順序顛倒的狀況。
*   彩色頁判斷需分別檢查嵌入圖片、整頁色彩分布及向量圖形，避免固定步長取樣漏掉 A3 圖片；低彩度淡色網底不得單獨觸發彩色判定。

### 1.3 實質空白頁與排版異常檢核
*   自動掃描 PDF 每一頁的實質萃取文字量。
*   若某頁字元數極少（少於 10 個字）且非圖表頁，則判定為「**疑似實質空白頁**」，條列出頁碼供人工複查。

## 2. 系統架構與技術環境

*   **前端與互動框架**：Streamlit
*   **核心依賴套件** (`requirements.txt`)：
    ```text
    streamlit
    pypdf
    pymupdf
    python-docx
    ```
*   **雲端部署限制解鎖** (`.streamlit/config.toml`)：
    ```toml
    [server]
    maxUploadSize = 1000
    ```
    （允許最大 1GB 檔案上傳，並在程式端加入檔案總大小防呆計算與攔截機制）。

---

## 3. 程式碼基準邏輯與字串處理規範

*   **頁碼格式化函式規則**：
    所有輸出的頁碼清單必須將連續頁面自動縮減為區段（例如 `1-6、8-10`），且多個區段或單頁之間必須使用**頓號（`、`）**連接，嚴禁使用逗號加空格。
*   **尺寸判定標準**：
    透過 `fitz` (PyMuPDF) 讀取頁面矩形 `page.rect`，面積大於 `600000` 點者判定為 A3，其餘為 A4。
